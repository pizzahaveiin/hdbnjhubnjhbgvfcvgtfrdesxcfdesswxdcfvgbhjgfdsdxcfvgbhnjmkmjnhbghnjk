KOT Workflow Configuration

Configure how Kitchen Order Tickets (KOT) are generated, printed, and routed to the kitchen.

⚡ Instant Dispatch

1. Automatic KOT (Quick Service / Fast Food)

KOT triggers automatically with zero manual clicks upon placing orders or entering checkout. Recommended for fast food, cloud kitchens, and self-order setups.

✓ Zero manual intervention ✓ Instant kitchen sync ✓ Auto-prints if printer paired
🍳 Manual Dispatch

2. KOT Only (Cafes & Casual Dining)

POS cart displays a dedicated "🍳 Send KOT" button. Waitstaff build the course and explicitly send the ticket to the kitchen when the guest finishes ordering.

✓ Dedicated "Send KOT" button ✓ Multi-course control ✓ Digital KDS only (No paper)
🖨️ Hybrid Screen & Paper

3. KOT & Print (Fine Dining & Stations)

POS cart displays both "🍳 Send KOT" and "🖨️ KOT + Print" buttons. Sends electronic ticket to KDS and prints a physical thermal kitchen slip for cooks.

✓ Dual Action Buttons ✓ 58mm / 80mm Thermal KOT Slips ✓ Digital Screen + Paper Hybrid
